# ByeAI by LAFU

**Bye, AI until you allow it.**

ByeAI blocks AI chat widgets, copilots, and AI service calls before they load. Published by **Maximum Effort AY**, Finland. Built by **LAFU** ([lafu.fi](https://lafu.fi)).

## Install locally

1. `chrome://extensions` → Developer mode → Load unpacked
2. Select `extension/`

## Chrome Web Store

| Doc | Purpose |
|-----|---------|
| `docs/STORE_LISTING.md` | Listing copy |
| `docs/PRIVACY_CHROME_FORM.md` | Privacy tab answers |
| `docs/PRIVACY_HOSTING.md` | Deploy to lafu.fi |
| `scripts/package.ps1` | Build ZIP |

**Privacy URL:** `https://lafu.fi/privacy.html`
